# yuriafp.github.io

Personal site and project hub, built with Blazor WebAssembly and hosted on
GitHub Pages.

**Live at [yuriafp.github.io](https://yuriafp.github.io)**

Single page, dark theme, bilingual with a PT/EN toggle in the header. Runs
entirely in the browser — there is no back end.

The project cards are not hardcoded here. Each public repository describes
itself through a `.portfolio.json` at its root, and a scheduled workflow
collects them once a day.

## Running locally

```bash
dotnet run
```
